# 📝 Weekly Report Generator | 周报/日报自动生成器

> 根据工作内容自动生成结构化周报/日报，支持4种模板（简洁/详细/OKR/KPI），一键导出Markdown/HTML

## ✨ 功能特点

- 4种报告模板：简洁版、详细版、OKR版、KPI版
- 交互式+JSON双模式输入
- Markdown/HTML/纯文本三种导出格式
- 历史报告存储与查询
- 零依赖，纯Python标准库实现

## 🚀 快速开始

将本仓库克隆到 Trae SOLO 的 skills 目录即可使用：

```bash
git clone https://github.com/vhengeee-coder/weekly-report-generator.git
```

详细用法请参考 [SKILL.md](./SKILL.md) 文档。
